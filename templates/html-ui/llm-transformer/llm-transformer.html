第 1 页 · 先说人话

Transformer
到底在算什么？

一句话：它就是一台超级会“划重点”的猜词机器。 你给它一句话，它把每个词变成一串数字，让词和词互相打分、互相参考，最后猜下一个词最可能是什么。

这页讲义不堆公式吓人。所有数学只保留 4 件事：变成数字、算相关、加权汇总、猜下一个。 看完你就懂 GPT、Claude 为什么能聊天。

→ 用方向键 / 按钮翻页共 11 页有可拖动的演示

🧮 本质是数学

没有魔法，只有矩阵乘法 + 概率。电脑最擅长的就是这个，所以能算得飞快。

👀 核心是注意力

读一句话时，重要的词多看两眼，不重要的少看。这叫 Attention。

🔁 堆很多层

一层没看懂就再看一层。GPT 堆了几十上百层，越堆越聪明。

打个比方： 把 Transformer 想成一个读书小组。每个词是一个同学，大家互相讨论“我和谁关系最密切”，讨论完每个人都带着全组的信息，再去猜下文。

第 2 页 · 第一步

文字，先变成数字

电脑看不懂汉字。它先把句子切成小块（Token），再把每块变成一长串数字。这串数字叫 向量 / Embedding，就像给每个词发一张“性格身份证”。

例： “我喜欢吃苹果”

我id 312
喜欢id 1842
吃id 903
苹果id 1205

每个词的向量有几百到几千个数字。意思越接近的词，向量越接近：“苹果”和“香蕉”近，“苹果”和“汽车”远。

0.21-0.831.04-0.560.67-0.15

↑ 这就是一个词向量的样子：一条彩色条纹，每个格子是一个数字——颜色只是把数字画出来方便人看（暖色 = 正数，冷色 = 负数，颜色越浓数值越大），模型真正计算时用的就是下面这排数字。

数学上在干嘛？

词 → 查表 → [0.21, -0.83, 1.04, …]
  • 查表： 有一张巨大的表，每行是一个词的向量，训练时慢慢学出来的。
  • 距离 = 语义： 用点积 / 余弦算两个向量像不像，后面注意力就靠它。
  • 国王 - 男人 + 女人 ≈ 女王，这类关系居然能被向量算出来。

第 3 页 · 第二步

光有词不行，还得知道顺序

“狗咬人”和“人咬狗”，词一样，意思完全反了。Transformer 本身不按顺序读，所以要额外给每个位置加一个 位置信号。

大白话做法

给每个词的向量 再加一串位置数字：第 1 个词加一组波纹，第 2 个词加另一组，就像给每个人贴上座位号。

最终向量 = 词向量 + 位置向量

位置向量常用正弦 / 余弦波，不同位置波形不同，模型能从波形里读出“谁在前、谁在后、隔多远”。

为什么用波？

  • 连续： 相邻位置波形相近，模型知道它们挨着。
  • 可外推： 句子再长，波形公式还能继续算。
  • 相对距离： 两个位置的波一对比，就能算出间隔。

现在的模型多用 RoPE 等旋转位置编码，思想一样：把顺序揉进数字里。

第 4 页 · 核心来了

注意力：谁该多听谁说话

读 “它很甜” 里的 “它” 时，你的大脑会自动回头看前文的 “苹果”。Transformer 做同一件事：每个词都回头给其他词打分，分高的多采纳它的信息。

点一个词，看看它在关注谁： 颜色越深、条越长，说明关注越多。试试点 “它”。

“苹果” 在关注谁？

这就是注意力权重：一排加起来等于 100% 的比例。模型不是平均听所有人，而是学会了挑重点。

第 5 页 · 拆开注意力

Q、K、V：提问、标签、内容

每个词会变出 3 个新向量，名字吓人，意思很土：

Q · Query · 我想找什么

像搜索框里打的关键词。
例：“它” 的 Q 是 “我在指代哪个东西？”

K · Key · 我是什么

像视频标题 / 商品标签。
例：“苹果” 的 K 是 “我是一个水果名词”

V · Value · 我带来的信息

像点开后看到的正文。
如果 Q 和 K 对上了，就把这个词的 V 加进来。

数学上怎么变出来的？

Q = X × Wq  ·  K = X × Wk  ·  V = X × Wv

X 是词向量，Wq / Wk / Wv 是三块可学习的矩阵。说白了：同一个词，乘不同的矩阵，就得到不同的分身。 训练就是在调这些矩阵里的数字。

第 6 页 · 唯一要记的公式

注意力公式，其实就 3 步

Attention(Q,K,V) = softmax( Q KT / √d ) × V
1

打分：Q · K

每个词的 Q 去和所有词的 K 做点积。点积越大 = 越对味。得到一张“相关程度表”。

2

除以 √d：别让分数爆掉

向量维度 d 越大，点积越容易变得巨大。先除以 √d 把数值拉回正常范围，不然下一步会失灵。

3

Softmax 变比例，再加权 V

把分数变成加起来 100% 的权重，再按权重把所有 V 混合，得到这个词的“升级版向量”。

注意力热力图长这样（每行加起来 = 100%）

行 = 正在看的词，列 = 被看的词。对角和代词回指处最亮，就是模型学到的阅读习惯。

第 7 页 · 互动演示

Softmax：把分数变成“注意力比例”

原始分数可正可负、加起来也不是 100%。Softmax 做两件事：先取指数放大差距，再除以总和归一化。 拖动下面滑块，看“温度”怎么影响专注程度。

温度 = 1：正常分配，最相关的拿走一半多。

温度低 → 更果断

差距被放大，赢家通吃。模型很确定时就像这样。

温度高 → 更平均

谁都分一点，模型更发散。你调 ChatGPT 的 temperature，调的就是这个感觉。

第 8 页 · 多头注意力

一个小组不够，就开 8 个组

只算一种“相关”太单薄。于是把注意力复制成多份，叫 多头（Multi-Head）：每个头关注一种关系，最后拼接起来。

头 1看语法
主谓宾关系
头 2看指代
“它”指谁
头 3看相邻
前后词搭配
头 4看情感
褒义还是贬义
头 5看主题
全文在讲啥
头 6看时间
先发生什么
头 7看格式
代码 / 标点
头 8看远距离
开头呼应结尾
MultiHead = 拼接(头1, 头2, …, 头h) × Wo

大白话：8 个专家各看一个角度，写好笔记，再汇总成一份报告。 头越多，看问题越全面，代价是算得越贵。

第 9 页 · 注意力之外

消化、保底、防走偏

前馈网络 FFN

注意力负责“跟别人交流”，FFN 负责自己一个人想一想。就是两层全连接：先放大、加非线性、再缩回来。

FFN(x)= max(0, xW₁+b₁)W₂+b₂

残差连接

每一步的结果都 + 回原来的 x。像改作文：不是重写，是在原文上批注。深层网络也不会把原意弄丢。

输出 = x + 子层(x)

LayerNorm

每层结束把数字拉回统一尺度：均值 0、方差 1 附近。防止数字越算越大、训练炸掉。

Norm(x)= (x-μ) / σ
记住分工： Attention = 横向交流（词与词之间），FFN = 纵向思考（词自己加工），残差 + Norm = 保证几十层叠下去不崩。

第 10 页 · 拼成完整一层

一层 Transformer，全流程

输入向量 X→多头注意力→+ 残差 & Norm→前馈网络 FFN→+ 残差 & Norm→输出给下一层

堆叠 = 越读越懂

  • 浅层： 学词法、相邻搭配
  • 中层： 学语法、指代、句式
  • 深层： 学语义、逻辑、意图

GPT-3 有 96 层，现在的大模型更多。每层参数都靠训练学出来。

因果掩码：不能偷看未来

生成文字时，第 3 个词只能看前 2 个词，不能偷看答案。实现办法：把注意力表里未来的位置分数设为 -∞，Softmax 后就是 0。

这就是为什么它能一个词一个词往外蹦。

第 11 页 · 最后一页

训练，就是海量猜词游戏

最后一步很简单：模型把整句话的理解压成一个分数表，对词表里每个词打分，Softmax 成概率，概率最高的，就是它猜的下一个词。

训练时

拿海量文本，遮住下一个词让它猜。猜错了，就用反向传播微调所有 W 矩阵，下次猜得准一点。重复万亿次，就是预训练。

聊天时

猜出一个词 → 把它拼回输入 → 再猜下一个。循环往复，就成了你看到的逐字输出。

一句话总结全讲义： Transformer = 把词变成向量 → 用 Q/K 算谁该关注谁 → 用 V 混合信息 → FFN 消化 → 堆很多层 → 猜下一个词。所谓智能，很多时候就是这套数学算得足够大、足够准。
