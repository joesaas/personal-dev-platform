# HTML UI 模板库

沉淀“做页面时可以直接抄的整页风格”，不是组件库、不是设计规范文档。
每个模板自包含：一个目录就是一个可直接打开、可直接复制改文案的完整 HTML 页。

## 目录

| 模板 | 说明 | 入口 |
| --- | --- | --- |
| `llm-transformer/` | 大白话动态讲义页：暖纸底 + 衬线标题 + 卡片页 + 底部翻页导航，含注意力条形图、热力图、Softmax 温度滑杆等原生 JS 演示 | `llm-transformer/llm-transformer.html` |

## 新模板入库约定

1. 一个目录一个模板，目录名用模板名的小写短横线形式；
2. 目录内必有两样：原 HTML 文件（有出处的注明出处与导出日期，原样不动）+
   一篇 README（讲清这页长什么样、设计要素、复用方法、适用与不适用场景）；
3. 保持单文件、零框架：模板本身不引入构建步骤，改文案即用；
4. 入库后在本文件表格里加一行，并同步仓库根 README 的目录一节。
